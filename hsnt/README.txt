There are two scripts here:
1. preprocessing.py: This one contains the necessary functions to perform the preprocessing
2. Ni_single_view_data_preprocessing.py: This one is dedicated to preprocess the Ni single-view datasets using functions from preprocessing.py

Note:
All the necessary libraries are already dependencies of MBIRJAX.So, just activate your MBIRJAX environment and run Ni_single_view_data_preprocessing.py.
